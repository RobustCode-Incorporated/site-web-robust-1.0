07 / DEFENSIVE PLAYBOOK

Signals need context. Controls reduce impact.

01

Segment

Separate guest, student, and administrative devices; apply client isolation where appropriate.

02

Filter

Use approved DNS filtering and firewall policy; log decisions without intercepting private traffic.

03

Rate-limit

Apply bounded server-side quotas and clear 429 responses on services you operate.

04

Investigate

Correlate timing, route, response, and user impact. Avoid attributing intent from one indicator.

08 / 30-MINUTE CLASSROOM EXERCISE

Investigate the signal. Explain the evidence.

00–05

Consent & scope

Review class rules, fictional topology, and what the simulator cannot access.

05–10

Recon concepts

Inspect fixture inventory. Distinguish public network details from privileged local visibility.

10–16

Generate evidence

Run browsing and check-in pattern scenarios. Compare interval regularity and route repetition.

16–21

QR / AP tabletop

Review warning signs. Discuss rogue AP risks without connecting to or creating an access point.

21–26

Blue-team response

Switch modes; compare modeled 403/429 interventions and discuss segmentation and rate limits.

26–30

Report & assess

State evidence, uncertainty, control, and one follow-up question. No real device data is collected.

Student worksheet and assessment criteria

Worksheet: Which repeated signals appeared? Which response changed in Blue Team mode? What evidence is fictional? What additional evidence would be required in a real, authorized investigation? Which control would reduce impact without monitoring private content?

Scoring (0–2 each): identifies repeated pattern; separates observation from inference; explains a relevant defense; respects authorization and privacy. Maximum: 8 points.
